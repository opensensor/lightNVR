# Настройки интерфейса и избранные камеры

Backend предоставляет личный режим интерфейса и список избранных камер для вошедшего пользователя. Идентификатор пользователя берётся только из проверенного сервером контекста аутентификации.

## API

`GET /api/ui/preferences` возвращает `{ "ui_mode": "auto", "configurable": true }`. Допустимые режимы: `auto`, `mobile` и `desktop`. Значение `auto` используется по умолчанию без строки в базе данных.

`PUT /api/ui/preferences` принимает объект ровно с одним строковым полем `ui_mode`. Ответ имеет тот же вид, что и GET. Неизвестные поля и неподдерживаемые режимы отклоняются с HTTP 400.

`GET /api/ui/favorites` возвращает `{ "favorites": [{ "camera_uuid": "…", "created_at": 0 }], "configurable": true }`. Список отсортирован по времени добавления, затем по UUID. Камеры без текущего разрешения `AUTHZ_LIVE_VIEW` в ответ не попадают.

`POST /api/ui/favorites` принимает объект ровно с одним полем `camera_uuid`. Ответ HTTP 200 содержит UUID и исходное время добавления. Повторное добавление идемпотентно и не меняет это время. Отсутствующая и недоступная камера отвечает одинаковым HTTP 404.

`DELETE /api/ui/favorites/:camera_uuid` возвращает `{ "success": true }`. Удаление идемпотентно и затрагивает только строку текущего пользователя, в том числе если доступ к камере уже отозван.

Неаутентифицированный запрос получает HTTP 401. Для demo-, scoped-token- и других контекстов без реального пользовательского ID GET возвращает значения по умолчанию с `configurable: false`; изменения отвечают HTTP 403. В запросах нельзя задавать `user_id`.

## Хранение данных

Миграция `0088_user_ui_preferences_favorites.sql` добавляет расширяемую таблицу `user_preferences` (JSON-значение по ключу) и `user_favorites`. Обе таблицы каскадно удаляются вместе с пользователем. Избранное также удаляется при удалении камеры. Составной первичный ключ запрещает повтор избранного для одной пары пользователь/камера.

Режим `auto` хранится как отсутствие ключа `ui_mode`. Другие режимы сохраняются как JSON-строки. Список избранного ограничен `MAX_STREAMS`, что совпадает с максимальным числом камер в приложении.

## Файлы backend

- `src/database/db_ui_preferences.c`, `include/database/db_ui_preferences.h` — операции хранения.
- `src/web/api_handlers_ui_preferences.c`, `include/web/api_handlers_ui_preferences.h` — проверка запросов, аутентификации и доступа к камерам.
- `src/web/libuv_api_handlers.c` — регистрация маршрутов.
- `tests/unit/test_api_handlers_ui_preferences.c` и запись в `tests/unit/CMakeLists.txt` — проверки API, изоляции, повторов, доступа и каскадного удаления.
- `include/database/db_embedded_migrations.h` — сгенерированное представление миграции.

Встроенный список миграций обновляется командой `python scripts/generate_embedded_migrations.py --update db/migrations include/database/db_embedded_migrations.h`.
