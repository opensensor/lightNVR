# T7.171 — named plan, filter and recording controls

All 29 assigned `jsx-a11y/control-has-associated-label` occurrences are resolved
with explicit accessible names in the six owned components. Existing translated
labels and tooltip strings supply the names. No new translation key, dependency,
exception, suppression, baseline change or shared-test edit was needed.

The source changes only add `aria-label` attributes. Native input/button/link
semantics, classes, IDs, handlers, disabled rules, drag payloads and hrefs remain.
Many form controls already had implicit/explicit native labels; this evidence
separates scanner recognition from browser behavior rather than claiming every
reported control previously lacked a browser name.

- LiveBuildingPlan: the shared camera-coverage range gets its visible label;
  width and height use their existing translated labels. Both direction/FOV
  instances are exercised, including native slider keys and saved geometry.
- LiveOperatorNavigator: search uses its existing localized label. Each camera
  action uses the existing visible camera name and location (including the
  localized unassigned fallback), retaining its distinguishing context. Native
  Enter/Space and `application/x-lightnvr-camera` drag payload are preserved.
- PlanSketchControls: shared percentage inputs reuse the supplied label; tone
  buttons use their localized tone names; shape label/text/filled fields use
  the existing label text. Rect, label, wall and area branches are exercised,
  including per-point fields and normalized percentage updates.
- FiltersSidebar: hide uses its existing localized action; both date/time pairs
  use the existing Start/End labels. These are native date/time inputs: the label
  identifies the endpoint and their native input semantics identify the value
  type. Independent date/time values and filter updates remain intact.
- RecordingsGrid: configuration gear, configuration checkboxes, play/download/
  timeline/delete actions, show-filters and select-all are explicitly named.
  Select-all uses the existing stable action translation; the visible selected
  count is unchanged. The download tooltip still includes the file size.
- RecordingsTable: column checkboxes and the reported show-filter/play/download/
  timeline/delete controls use their existing labels. Nonreported table gear
  naming is not expanded under this task.
