# T28.2 — terminal read-only segment writes

Added EROFS to the existing terminal ENOSPC/EIO branches for ordinary video,
final video keyframe and audio packet writes in `mp4_segment_recorder.c`. Each
branch preserves its negative error through existing resource cleanup, so a
later successful trailer cannot turn the failed segment into success. The final
video branch now records the same packet I/O telemetry as ordinary video/audio.
Timestamp-recovery behavior is unchanged; no dependencies or broader recorder
rewrite were introduced.
