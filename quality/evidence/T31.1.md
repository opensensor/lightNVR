shutdown and requires the current state remain discoverable until callback

completion must destroy both tracked mutexes once, leave an empty registry,
and report no pthread destruction error.

still executes. Addresses are retained as integers and no freed state is
accessed. Media stops/timestamp helpers are deterministic link seams. The child
is reaped and the test target has a separate 15-second CTest timeout.
