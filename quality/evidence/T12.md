## Design and consumption

`loadContract` resolves every reference from local YAML under docs/api, rejects
remote/traversal refs, verifies the OpenAPI dialect, detects duplicate component
names, and canonically merges components. This preserves named types and avoids
the invalid response-path indexing produced by generic ref-parser bundling.
The full canonical OpenAPI document and operation/status/header/role-selection
manifest are test-only files in `tests/contracts/generated/`. They must not be
imported into browser code.

Runtime validators are minified browser ESM, compiled with Ajv2020 strict schema
checking and formats. Standalone code enforces JSON-in-string contentSchema
(nonempty eptz_config) and explicitly annotated UTF-8 byte limits; empty
 eptz_config retains its documented disabled meaning. Annotation-only byte limits
are not confused with JSON Schema's Unicode-code-point maxLength. Runtime source
omits schema descriptions/source metadata. Neither Ajv nor the generator is a
browser dependency. Header/status and role-selection metadata remains available
for independent T18/typed-client checks; schema validity alone does not prove
server authorization or side effects.

Import a named boundary, for example:

```ts
import { validateClientConfig } from './api/generated/validators.mjs';
```

Each validator has a corresponding type guard accepting unknown and exposes
structured validation errors. The generated .mjs implementations are compiler
output, paired with strict .d.mts declarations; they are not unchecked handwritten
application escape hatches. T34 should inventory this narrow generated-code
exception separately from remaining legacy JS.

Ajv's function-property assignments prevented useful tree shaking when all
validators lived in one module. The final generator creates one module per
schema plus a named-export index and generated sideEffects:false package marker.
The marker applies only to generated validators, whose top-level operations
initialize private functions. Avoid namespace-importing all validators in app
code. No handwritten implementation is excluded by this marker.
