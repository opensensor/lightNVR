## Scope and method

Read the T3 S5/S6 inventory in `quality/operational-coverage.json` and existing
retention, SQLite, pressure, deletion and MP4 boundary tests before editing.
The existing quota/protected and disabled-stream tests are preserved. Added12
Unity cases across five implementation files (two existing unit sources, two
operational sources, one CMake registration fragment). Total:70 cases in6targets.
The two original pure pressure targets remain unchanged.

- Enabled streams now exercise inherited(-1), unlimited(0), finite(3days) and
  global14day retention using real SQLite and real disposable files. Expired
  files disappear; protected, recent and unlimited rows/files survive. A held
  descriptor to protected media stays readable.
- Exact-path `unlink` faults inject EROFS/EIO during real deletion. Assertions
  inspect retained media/metadata, `deletion_pending`, durable journal
  `retry_wait`/attempt count, integrity_check, and eventual real deletion after
  fault removal. Protected media survives both phases. Retry deadlines advance
  only in the private database. Tests clear their own ledger between cases.
- Root unavailability is an owned-directory rename, restored before assertions;
  it never unmounts a volume. The expected contract preserves expired/protected
  rows until storage is restored.
- SQLite read-only protection updates use the actual connection's query_only
  setting; SQLite fullness uses its real pager max_page_count=page_count+8 and
  at most256 recording insert attempts. Both assert preserved prior protected
  metadata, integrity_check and successful API writes after restoration. No
  host filesystem is filled, chmodded or remounted.
- A foursecond32×32,24fps MPEG-4 fixture is generated with native FFmpeg. Real
  demux/segment/mux code receives ENOSPC, EIO or EROFS on the fourth selected
  output packet; tests require immediate error, closed resources and telemetry.
  Recovered output is opened and decoded, not merely checked for existence.
  Another case injects EROFS at output open and verifies recovery.
- The production writer loop runs under deterministic pressure/sleep/segment
  seams. No segment opens during pressure; cleanup is requested; recording
  resumes after two simulated seconds; shutdown while paused opens nothing.
  This is explicitly not a real-volume or end-to-end metadata test.

All new database/media roots use mkdtemp; previous fixed database paths in the
owned tests are removed. GNU linker wraps affect only test executables. Existing
heavy dependency registration is preserved; operational CTests timeout at20s,
retention/SQLite tests at30s. Reproduction and injection details are in
`tests/operational/storage/README.md`.
