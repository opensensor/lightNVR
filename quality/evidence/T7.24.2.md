## Correction and static argument

`patches/faac/0001-bound-input-pointer-arithmetic.patch` changes only private `frame.c`, `faac.c` and `faac_internal.h`. The private call chain transports `const void *` directly. A typed view is selected only after the input format is known. The 16-bit, 32-bit and float loops use indexed reads rather than incrementing a channel-offset pointer after its last read. Public ABI, codec configuration, scaling, float screening and packed24 conversion remain unchanged.

For N samples in complete channel groups, C validated channels and map m in `[0,C-1]`, each executed index is `i*C+m`, with `0 <= i < N/C`. Its maximum is `N-C+m <= N-1`; no pointer is formed for `i == N/C`. Public input-count limits bound the arithmetic, and zero-group input exits before reads. Removing the unused terminal increment establishes this property by inspection; ASan passing alone would not establish it. Format-correct casts also avoid the unnecessary int32 intermediary for two-byte-aligned or packed input.
