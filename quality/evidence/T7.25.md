## Tests before implementation

The coordinator authorized direct test production because worker slots were
occupied. The test translation unit includes the actual `db_core.c` implementation
to exercise its static helper without changing production visibility. Wrappers
only interpose filesystem metadata calls to schedule exact replacement after a
successful inspection; files, directories, SQLite backup and restore are real.
All objects are inside a unique private temporary root.

- Parent replacement: immediately after inspection, rename the inspected backup
  directory and create a replacement directory at its old path containing a file
  of the same name. Current cleanup deletes the new replacement bytes and leaves
  the original inspected artifact behind. The oracle requires the replacement
  survive and the inspected artifact be removed through an anchored directory.
- Symlink leaf replacement: replace the inspected regular file with a symlink.
  Current cleanup removes that unvalidated entry. The target bytes survive, so
  this does **not** demonstrate symlink-target deletion; the oracle preserves
  both the new entry and its target, consistent with the normal skip-link policy.
- Regular leaf replacement: replace the inspected regular file with another
  regular file containing distinct bytes. Current cleanup deletes those new
  bytes. The oracle requires them to survive.
- Controls: selective cleanup preserves published backups, unrelated files,
  existing symlinks and directories; missing directories are harmless;
  non-directory input fails without mutation; a disposable real SQLite database
  opens read-only without cleaning its backup directory, then backs up and
  restores its original sample value successfully.

## Design boundary

Directory-fd-relative inspection/deletion prevents parent-path redirection, but
`fstatat` followed by `unlinkat` still cannot atomically bind the leaf deletion to
its earlier inode. A full identity-preserving design must account for that gap;
an additional pre-unlink check alone would not establish race freedom. The
coordinator has a bounded proposal for held candidate descriptors and private
quarantine rename/identity verification, with no-overwrite restoration or
preservation on mismatch. No production implementation or guarantee is claimed
until that design and its failure-path controls are completed.
