# T7.168.2 — preserve native checkbox state during zone selection

The first checkbox activation now records its native value before selecting the
zone card. The card still receives bubbled clicks; it defers selection only for a
checkbox target, whose change handler updates enabled state and selects the card.
There is no event suppression, synthetic toggle, asynchronous selection or DOM
change. Native pointer/keyboard/label behavior and focus remain intact.

Production scope is only ZoneEditor checkbox/card event ordering. The approved
T7.162 Node fixture extension supplies actual event targets and invokes click
before change, retaining exactly one enabled update and one checkbox-driven
selection. Existing browser card-click counts and geometry assertions are unchanged.
