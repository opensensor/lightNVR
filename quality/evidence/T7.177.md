## Remaining defects and bounded correction

- The ZIP filename had an orphan visible label, despite a valid aria-label.
  A per-instance `useId` now connects the visible label and input. The two radios
  also shared `dl-mode` outside a form: selecting the second modal's sequential
  option cleared the first modal's checked ZIP radio while leaving its ZIP
  component state visible. Per-instance group names preserve native independence.
- Stream Config reused input/select IDs and their explicit label references.
  Chromium resolved second-instance labels to first-instance controls. All its
  field IDs/references now use a stable instance prefix, retaining original
  suffixes, input names, values, permissions, callbacks and bounds. Resolution
  and FPS are display-only spans; their orphan labels become plain paragraphs
  with identical classes. Modal, form and action-button IDs remain unchanged.
- Route and collection editors supplied shared prefixes to the real conditional
  CollectionSelectorBuilder. Each owning parent now supplies an instance prefix;
  the selector implementation and callback contract are unchanged.
- Destination and StaticCollectionMembers already use correct native nested
  labels, including conditional TLS/secret controls and camera selection. Their
  source files are unchanged and passing controls are reported as such.

Only approved consumer compatibility paths changed: T7.167 resolves the original
field suffix in its existing assertions/locators, and StreamsPage's name, URL,
active and recording getters use the same suffix selectors. All other modal,
form, action, name, class and callback contracts remain. The historical Selenium
end-to-end suite was not executed; actual Chromium exercises the changed fields,
and the existing T7.167 browser/callback suite passes unchanged assertions.

Fixed dialog-heading IDs in Destination/Route/CollectionManager and fixed
Stream Config modal/form/action IDs are outside input-label ownership. They are
not claimed to become globally unique by this task. No heading fix was bundled.
