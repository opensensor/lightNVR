It checks the actual upstream HEAD and superproject gitlink, tracked manifest/patch identities, original/copied source bytes, complete file mapping, build roots and the compiler database. Generated paths remain intact in reports and source records; no `#line` disguise or original-path rewriting is used.

Omitting any required compiled FAAC unit or previously selected source prevents successful scanner status.

The generated build/source mapping, tracked manifest/table/patch, compiler database and CodeQL source archive are copied into the report artifact with SHA-256 evidence. The optional filtered cppcheck database is also archived. This connects original upstream identity to actual compiled/scanned paths while preserving raw scanner output.
